# Research Principles

The Empire Codex is a research-first project. Its purpose is to help us understand Empire before making implementation decisions.

## Working motto

**Preserve. Understand. Rebuild.**

The rebuild phase is intentionally deferred until the research foundation is strong enough to support it.

## Core rules

### 1. Evidence before conclusions

If a claim is uncertain, mark it as uncertain. If sources disagree, preserve the disagreement rather than forcing a false synthesis.

### 2. Primary sources whenever possible

Prefer manuals, source code, author statements, magazine articles, contemporary reviews, mailing lists, Usenet posts, disk images, and other period evidence.

Secondary sources are useful, but they should not silently become the foundation for claims.

### 3. Separate facts from interpretation

Each major chapter should distinguish:

- Historical evidence
- Interpretation
- Project relevance
- Open questions

### 4. Human stories matter

Empire is not only a rules system or a codebase. It moved through people: creators, maintainers, players, university labs, hobbyist groups, publishers, reviewers, and later preservation communities.

The Codex should document human context wherever evidence allows:

- Who made or maintained a version?
- What constraints did they face?
- How did players encounter the game?
- What did people remember, value, criticize, or change?
- How did the game travel through institutions, magazines, user groups, BBSes, Usenet, and personal networks?

Avoid reducing the project to mechanics alone.

### 5. Modest claims

Avoid language such as "definitive," "ultimate," or "canonical." The work should earn trust through citations, clarity, and willingness to revise.

### 6. Public does not mean performative

The repository may be public, but its first audience is the project team. The main test for every artifact is whether it helps us make better decisions later.
