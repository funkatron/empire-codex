# Empire Codex

A technical and historical study of the Empire strategy game and the design of a modern Empire-inspired web implementation.

## Mission

This repository serves as:

- A digital archive of publicly available historical material.
- A rigorously cited research project.
- A game design analysis.
- An implementation notebook for a modern remake.

The goal is to preserve the history of Empire while documenting the engineering and design decisions needed to build a faithful modern successor.
