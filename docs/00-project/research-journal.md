# Research Journal

Chronological notes about what was investigated, what was found, and what remains uncertain.

## 2026-07-03 — Project start

### Context

The project began from a personal memory of playing a DOS-era version of Empire on an IBM-compatible machine with CGA/EGA graphics. The immediate goal is not to write implementation code. The immediate goal is to understand the game's history, evolution, mechanics, and human context well enough to support future design work.

### Initial framing

We agreed that the project should avoid hyperbole. The public may or may not care about a new implementation. The Codex should primarily serve the project team as a research notebook, evidence ledger, and decision-support artifact.

### Human-centered correction

A key early correction: human stories must be first-class. The game should not be treated only as mechanics, source code, or UI. The research should include creators, maintainers, players, publishers, reviewers, user groups, and preservation communities.

### Initial source anchors

The first source anchors identified for deeper accession are:

- Walter Bright's Classic Empire site and history pages.
- Classic Empire instructions.
- Empire: Wargame of the Century manual, version 5.0.
- The Wargaming Scribe's historical synthesis, "Game #34: Empire."
- Empire Deluxe manual.

### Open questions

- Which exact DOS release corresponds to the remembered CGA/EGA experience?
- How many distinct code lineages used the name Empire?
- Which mechanics were present in the earliest playable versions?
- What was changed by Interstel / Northwest Software for the commercial DOS release?
- What human networks carried the game between Caltech, DECUS, hobbyists, and commercial publication?
- How did players describe the experience at the time, rather than in retrospect?
